# ترقية CodeIgniter إلى 3.1.13

أُنجزت محليًا بتاريخ 2026-10-22 على PHP 8.5.12، دون تشغيل VPN أو الاتصال بـOracle.

## النتيجة وطريقة الدمج

- أصبح `system/core/CodeIgniter.php` يعرّف `CI_VERSION = '3.1.13'`.
- استُخدمت نسختا 3.1.11 و3.1.13 الرسميتان مع نسخة المشروع الحالية في دمج ثلاثي. حُفظت التعديلات المحلية السابقة، بما فيها التعديلات الملتزمة في Git وإصلاحات PHP 8.5.12.
- طُبّق 178 ملفًا: 176 ملفًا من الإطار، منها أربعة ملفات جديدة لواجهات الجلسات وwrappers، وملفا `application/config/mimes.php` و`user_agents.php` المطلوبان في تعليمات الترقية.
- حُلّت تعارضات FTP وUpload وXML-RPC وSession_driver مع إبقاء دعم كائنات PHP 8، وحراسة الدوال المتقادمة، وقيمة كعكة الحذف الفارغة، واعتماد خيارات SameSite من CI 3.1.13.
- بقيت ملفات MX الثمانية وindex.php وملفات اللغة العربية الأربعة عشر مطابقة بالـSHA-256 لنسخة ما قبل الترقية. احتُفظ أيضًا بتخصيصات الإطار السابقة، مثل base_url وsess_update.
- تعريفات MIME تتضمن الامتدادات الرسمية الـ173 وتحتفظ بالاسمين المحليين `docx: inode/x-empty` و`xlsx: application/octet-stream`. الملف يعيد المصفوفة لـCI ويُبقي متغير `$mimes` للمستهلكين القدامى.
- حُفظت تسميات المتصفحات المحلية، وأضيف تمييز Edge الحديث قبل Chrome. عُدّل `Login::check_browser()` للحفاظ على قبول Chromium Edge/Opera حسب إصدار Chrome الموجود في User-Agent، وعلى قبول Edge في iOS حسب إصدار Safari الموجود فيه؛ حدود الإصدارات القديمة ورفض Internet Explorer وOpera القديم بقيت كما كانت.

## التحقق بعد التحديث

كل الاختبارات التالية نجحت على النسخة المطبقة:

| الفحص | النتيجة |
|---|---|
| تجميع PHP مع E_ALL وshort_open_tag=Off | 3234 ملفًا، دون أخطاء أو تحذيرات تجميع |
| الوراثة والتواقيع داخل controllers | 468 تعريف Controller و5 تعريفات أخرى، دون أخطاء؛ 9 ملفات بلا أصناف تُفحص صياغتها فقط |
| MX والـmodules الفعليان مع تطبيق مصطنع | 75 فحصًا للمسارات والتحميل وModels وViews وConfig وLanguage |
| تعريفات الملفات والمتصفحات | 45 فحصًا باستخدام CI_Upload وCI_User_agent ومنطق دخول المشروع الفعلي |
| الإطار والجلسات | حقن الاعتماديات، PHP8 session wrapper، رفض معرف غير معروف، حفظ واستعادة العربية والأصفار الأولى، تحديث الوقت والحذف، GD وMIME |
| Views وHelpers وCAPTCHA ومكتبات الاتصال والتصغير وXML-RPC | 167 فحصًا |
| الربط المالي مع بدائل OCI | 1091 فحصًا |
| تصدير CSV من Controller فعلي دون تشغيل constructor | 19 فحصًا |
| التقارير وملفات HTML/A4/Excel المصطنعة | 475 فحصًا |
| الاعتماديات | كتابة وقراءة XLSX، الكاتب القديم، العربية والأصفار الأولى والصيغ وRTL، الباركود وQR، تهيئة Jasper دون طلب خارجي، والتشفير |
| JavaScript للتقارير | الإجماليات والتفضيلات والعرض وترتيب تحميل السكربتات |

استُخدمت بيانات وملفات مصطنعة. لم تُختبر جلسة مستخدم على Oracle أو عمليات العمل أو خادم Jasper الحقيقي. احتاج اختبار الاعتماديات التشغيل خارج عزل الملفات المحلي بسبب فحص قابلية القراءة في Windows؛ نجح الاختبار نفسه دون تغيير مكتبات Excel.

أوامر إعادة الاختبار موجودة في [README](README.md). لا تستخدم `check-oracle.php` ضمن الاختبارات المحلية.

## نسخة ما قبل الترقية

المجلد: `C:\xampp744\htdocs\gfc\temp\php85\ci3113-upgrade\before`

يحتوي نسخة system وMX وindex.php وملفي الإعدادات وLogin.php قبل التعديل. ويحفظ المجلد الأب:

- `before-sha256.json`: بصمات الملفات الأصلية.
- `applied-sha256.json`: الملفات المطبقة وبصماتها، مع تحديد الملفات الجديدة.
- `retained-local-overrides.patch`: الفروق المحلية المحفوظة مقارنةً بـCI 3.1.13 الرسمي.
- الأرشيفين الرسميين ومجلدي المصدر ونسخة الدمج.

للرجوع، تُستعاد الملفات من `before`، وتُزال فقط ملفات الجلسات الأربعة المعلّمة `new: true` في سجل التطبيق. تبقى PHP 8.5.12 واعتماديات Composer كما هي؛ النسخة المحفوظة تحتوي إصلاحات PHP 8.5.12 السابقة للترقية. هذه ملفات محفوظة للرجوع وليست إجراءً نُفّذ أثناء التحديث.
